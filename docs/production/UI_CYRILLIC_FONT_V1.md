FONT-001 previously relied on the engine default and system fallback. The candidate now uses Open Sans variable at weight600/width100, with explicit Noto Sans Symbols and Noto Sans Symbols2 fallbacks. All three unmodified TTFs, original SIL Open Font License1.1 notices and metadata come from pinned google/fonts commit `6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec`. No font authorship is claimed.

The native FontVariation is assigned to the project Theme synchronously in App._enter_tree, before UI nodes enter. A font-free project Theme avoids loading imported font caches before a cache-free editor import. The first full import failure under custom_font is retained. Each imported font disables host system fallback. Complete notices are also stored in resource metadata to retain attribution in resource packs; this does not claim a platform export or legal release audit. The offline assembly source is `tools/create_archive_ui_font.gd`.

Source cmap coverage passes. The U+2192 arrow is absent from Open Sans and Symbols2; measured probes selected Symbols1 rather than altering source text. Unused Noto Sans/Math candidates remain scratch diagnostics and are not installed. Native glyph/shaping checks now pass with exactly the three bundled font families.
