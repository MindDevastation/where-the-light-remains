Square stepped piers, layered pointed/round portals, chunky brackets and readable bevel silhouettes are supported by the new kit/shape sheets. Sparse original celestial engraving; literal faction marks and exact proprietary armor/assets never enter shipping resources. Generated English/pseudo-writing, counts, dates and decorative UI copy are not approved text.

Do not add props directly behind prompts/control surfaces or across puzzle silhouettes. Those distances are visual targets, not a change to collision/player dimensions.

Depicted flames are emissive/static contribution where appropriate; existing Technical Baseline remains **normally 2–4 dynamic shadow lights**, 16.67 ms / GTX1060 6GB / 1080p60 Medium.
