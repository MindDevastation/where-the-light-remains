# Native Hub control leaf-prop review

Individually inspected fourteen 960x540 actual GameRoot/player images, seven on
Low and seven on Medium, software llvmpipe Forward+. Original shipping lights,
materials and camera; no extra studio light or image editing. Rendering and
physical primary/backup slots are hash-bound by results.json. The fixture uses
real local PANEL/TAKE_LENS/INSTALL_LENS steps and a quiet awakened projection;
actual E/awakening/persistence are separately tested in controls-progression-1.

| View, both presets | Observed result |
| --- | --- |
| hub_sleeping | Closed cover/ready lever beside original mechanism; loose lens and empty socket remain |
| panel_closed | Walnut grain and brass frame/grip readable; four corners retain static mounting plate |
| panel_open | Cover angles forward from left hinge; raised edge separates from static backing |
| panel_oblique | Hinge-side profile and open cover depth visible; no coplanar overlay or disappearing faces |
| lever_ready | Upright brass stem, walnut knob and fixed bearing readable next to installed lens |
| lever_pulled | Knob lowers/advances from the ready pose while base stays fixed; installed lens retained |
| hub_awakened | Open cover/pulled lever/installed lens retained, loose pickup absent |

Low preserves the pose distinction without glow/volumetrics. Current sleeping
Hub lighting remains dark. This is bounded fitting geometry/state readability,
not acceptance of the full console mounting/composition, core silhouette,
rotunda/Hub illumination or physical target GPU. Main stays unchanged; universal
panel skins/second lever shape are not claimed complete.
