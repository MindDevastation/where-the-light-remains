# Selected concept art

This tree contains approved production references grouped by purpose/stage.

- `environments/` — Stage environment/key/gameplay references
- `hero_props/` — central mechanism, wing devices, sigils, egg, final table
- `ui/` — menu/final/UI reference concepts
- `characters/` — character and pair mood references
- `memories/` — Memory I, Egg and Future-memory references
- `production_sheets/` — material, lighting and architectural language
- `_secondary/` — retained references that are explicitly noncanonical/secondary

Concept art never overrides gameplay/narrative specifications. `noncanonical_final_pair_scene.png` is retained only as a mood/reference artifact and must not be used to depict a reciprocal ending.
