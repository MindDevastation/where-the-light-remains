# Concept Art Intake

This directory will contain the **selected production reference art** for Where the Light Remains.

Do not treat every generated image as canonical. Only selected/approved images should be promoted into this folder structure.

Recommended structure once artwork is available:

```text
assets/concept_art/
├── environments/
│   ├── s00_prologue/
│   ├── s01_observatory/
│   ├── s02_wing_light/
│   ├── s03_wing_voice/
│   ├── s04_memory_first_meeting/
│   ├── s05_wing_lightness/
│   ├── s06_memory_egg/
│   ├── s07_wing_reflection/
│   ├── s08_wing_sincerity/
│   ├── s09_memory_future/
│   └── s10_s15_finale/
├── hero_props/
├── ui/
├── characters/
├── memories/
└── production_sheets/
```

For each approved image, the future asset index should record:

- filename;
- stage(s);
- related Asset Manifest ID(s);
- role: mood / gameplay layout / modeling reference / material reference / UI reference;
- canonical or secondary status;
- notes about what Astra/model production should preserve.

Character art will be generated from supplied screenshots of the in-game character models, so those reference images should be preserved separately from generated concepts.
