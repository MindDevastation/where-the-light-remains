# Character References

Character concept generation will use screenshots of the original in-game character models supplied by the project owner.

Store source screenshots separately from generated concepts so the provenance of each reference is obvious.

Recommended future structure:

```text
assets/characters/
├── references/
│   ├── heroine/
│   └── author/
└── approved_concepts/
```

Do not extract or redistribute third-party game assets. Final game characters should be original/stylized interpretations based on the approved references and project art direction.
